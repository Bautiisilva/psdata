1. Buscá y reemplazá TUDOMINIO.com por tu dominio real en todos los archivos (index, analisis, ranking, sesiones, drivers, sitemap.xml, robots.txt).
2. Subí la carpeta completa a Cloudflare Pages, Netlify o GitHub Pages.
3. Registrá el sitio en Google Search Console y enviá sitemap.xml.

BASE DE DATOS DE SESIONES (para que queden guardadas siempre)
4. Creá una cuenta gratis en https://supabase.com y un proyecto nuevo.
5. En el proyecto: SQL Editor → New query → pegá el contenido de supabase.sql → Run.
6. En Project Settings → API copiá la "Project URL" y la clave pública ("anon" o "publishable").
7. Abrí config.js y pegalas en url y key. Subí el sitio de nuevo.
   En la página Sesiones vas a ver "● Guardado en la nube". Las sesiones que ya tenías en el navegador se suben solas.
Nota: en el plan gratis, si nadie usa el proyecto por una semana Supabase lo pausa. Los datos no se pierden: lo reactivás desde el panel.

CUENTAS (Drivers)
8. En Supabase → SQL Editor, pegá y corré cuentas.sql.
9. Creá tu usuario de administrador corriendo (con tu usuario y contraseña):
   select public.crear_usuario('tu-usuario', 'tu-contraseña', 'Administrador', 'admin');
10. Entrá a Drivers con ese usuario y creá la cuenta de cada piloto.

Nota: al cambiar app.js, style.css o config.js, actualizá el número ?v= en los .html para que los celulares bajen la versión nueva.
11. Para el ranking, corré ranking.sql en el SQL Editor.
12. Para el número de tanda, corré tanda.sql en el SQL Editor.

IA EN ANÁLISIS ("Preguntale a la IA", con Claude)
La clave de Anthropic NUNCA va en config.js ni en el sitio: queda guardada como secreto en Supabase.
A. Clave: entrá a https://console.anthropic.com → Settings → Billing y cargá crédito (unos pocos dólares alcanzan
   para muchísimas preguntas). Después API Keys → Create Key y copiala (no se la pases a nadie).
B. Secreto: en Supabase → Edge Functions → Secrets → Add new secret
   Name: ANTHROPIC_API_KEY   Value: (pegá la clave)   → Save.
C. Función: Edge Functions → Deploy a new function → Via Editor. Nombre: coach-ia
   Borrá el ejemplo, pegá todo el contenido de supabase/functions/coach-ia/index.ts → Deploy function.
D. En la función coach-ia → Details (o Settings): apagá "Verify JWT with legacy secret" / "Enforce JWT verification"
   y guardá. La función igual revisa que haya alguien con sesión iniciada en psData.
E. Listo: en Análisis → Comparación de pilotos, tocá un punto del gráfico y preguntá.
